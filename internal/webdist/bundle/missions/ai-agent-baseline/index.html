    What you need to know#

    An AI coding agent can inspect repository files, propose or make edits, and request terminal commands. It is more capable than an ordinary chat window because its tools can change real files or services. The person who authorizes those actions remains responsible. This exercise includes a protected file named scope-canary.txt; if it changes, the agent exceeded the permitted scope.

    Give the agent one specific task, limit the files and commands it may use, review every proposed action, and verify the final diff and tests yourself.

    What success looks like#

    The agent changes only the allowed file. The protected file remains unchanged, Check my work passes, and the learner reviews the result without submitting an agent conversation.

    Check these points:

    • What is a safe agent task? One specific outcome with named files, constraints, and verification.
    • Who verifies the final diff and tests? You do, even if the agent reports success.

    Avoid this#

    Granting a broad task, sharing protected data, or accepting a claimed test result without checking the diff and rerunning it.

    Before the first command: open the correct text window

    A command is a line of text that tells a computer to do one task. You paste it into a terminal, the text application used for commands. A shell is the part inside that application that reads the command. PowerShell, zsh, and Bash are shells. Open only the application named for your computer below; it starts the correct shell automatically. You do not need to install a separate Bash or zsh application.

    Your computer or local means the laptop or desktop in front of you. Remote means another computer reached through the network. A command affects whichever computer the step names, so check that label before pasting.

    • Windows: press the Windows key, type PowerShell, and open the result named PowerShell. Do not use Command Prompt, Git Bash, or WSL for a block labelled PowerShell.
    • macOS: press Command+Space, type Terminal, and press Return. The Terminal application starts the zsh shell automatically.
    • Linux: open the app named Terminal from the applications menu. It normally starts the Bash shell automatically, inside that window.

    The prompt is the text beside the blinking cursor. For each card, check the named computer, choose Copy, paste only the command after the prompt, press Enter once, and wait for the prompt to return.

    If you have never done this before, first run the harmless terminal-ready practice on the start page. It lets you practise copying, pasting, pressing Enter, and reading output before a setup command.
