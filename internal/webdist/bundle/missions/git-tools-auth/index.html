    Before you start#

    Git is version-control software: it records file versions. A repository is a project folder with history; a clone is its separate local working copy. GitHub stores the shared online copy; GitHub CLI (gh) acts through your login.

    Setting Purpose Inspection
    GitHub login Authorizes GitHub actions Which account gh uses
    Git author identity Labels commits with name/email Effective values and their configuration source
    Branch and origin remote Select work and its online repository Prepared practice branch and credential-free URL

    A correct login does not set the commit author. A remote address must not contain a password or token. The repair below changes author identity only in this clone. GitHub Education is an optional student benefit application; waiting for approval does not block this Git practice.

    Inspect all three settings before changing one. If the login is right but the author is wrong, which repair would address the actual problem?

    Separate login from commit authorship

    Keep the intended GitHub account. Confirm the effective name/email from the practice clone, then use its local identity repair only if needed. Inspect the branch and origin independently. Do not reset another project to match this one.

    Optional: using the terminal

    A command is a line of text that tells a computer to do one task. You paste it into a terminal, the text application used for commands. A shell is the part inside that application that reads the command. PowerShell, zsh, and Bash are shells. Open only the application named for your computer below; it starts its configured shell. Follow the shell named below. You do not need to install a separate Bash or zsh application.

    Your computer or local means the laptop or desktop in front of you. Remote means another computer reached through the network. A command affects whichever computer the step names, so check that label before pasting.

    • Windows: press the Windows key, type PowerShell, and open the result named PowerShell. Do not use Command Prompt, Git Bash, or WSL for a block labelled PowerShell.
    • macOS: press Command+Space, type Terminal, and press Return. Terminal normally starts the zsh shell. If it uses another shell, run zsh for this session.
    • Linux: open the app named Terminal from the applications menu. It normally starts the Bash shell. If it uses another shell, run bash for this session.

    The prompt is the text beside the blinking cursor. For each card, check the named computer, choose Copy, paste only the command after the prompt, press Enter once, and wait for the prompt to return.

    If you have never done this before, first run the harmless terminal-ready practice on the start page. It lets you practise copying, pasting, pressing Enter, and reading output before a setup command.

      3. 05

        Sign in only when needed

        On your computer

        Run this only when the previous check showed no account or the wrong account. Enter the intended GitHub username. The command first tries to select an account already stored on this computer; otherwise it opens a new browser login. It does not remove another account.

        Show sign-in repair only if the account check failed (PowerShell on Windows)
        RunPowerShell on Windows
        & {
  $GitHubUser = Read-Host "Intended GitHub username"
  if ($GitHubUser -notmatch "^[A-Za-z0-9-]+$") { throw "STOP: invalid GitHub username" }
  gh auth switch --hostname github.com --user $GitHubUser
  if ($LASTEXITCODE -ne 0) { gh auth login --hostname github.com --git-protocol https --web }
  gh auth status --active --hostname github.com
}
        Show sign-in repair only if the account check failed (Terminal on macOS (zsh))
        RunTerminal on macOS (zsh)

printf 'Intended GitHub username: '; read -r github_user

if ! gh auth switch --hostname github.com --user "$github_user"; then gh auth login --hostname github.com --git-protocol https --web; fi
gh auth status --active --hostname github.com

      5. 07

        Set identity only if needed

        On your computer

        Use this step only if the previous check was empty or wrong. Enter the author name and a verified GitHub email or GitHub-provided no-reply email. This sets the identity only in the practice repository, so it cannot silently change your other projects. The email identifies commits; it is not an ETH password or login.

        Open GitHub email settings
        Show identity repair only if the name or email is wrong (PowerShell on Windows)
        RunPowerShell on Windows
        & {
  $GitName = Read-Host "Commit author name"
  $GitEmail = Read-Host "GitHub email or no-reply email"
  if ([string]::IsNullOrWhiteSpace($GitName) -or $GitEmail -notmatch "^[^@\s]+@[^@\s]+$") { throw "STOP: invalid name or email" }
  git config --local user.name "$GitName"
  git config --local user.email "$GitEmail"
  git config --show-origin --get user.name
  git config --show-origin --get user.email
}
        Show identity repair only if the name or email is wrong (Terminal on macOS (zsh))
        RunTerminal on macOS (zsh)
        (
printf 'Commit author name: '; read -r git_name
printf 'GitHub email or no-reply email: '; read -r git_email
if [ -z "$git_name" ] || ! printf '%s\n' "$git_email" | grep -Eq '^[^[:space:]@]+@[^[:space:]@]+$'; then printf 'STOP: invalid name or email\n' >&2; exit 1; fi
git config --local user.name "$git_name"
git config --local user.email "$git_email"
git config --show-origin --get user.name
git config --show-origin --get user.email

        If Blocked#

        If the editor is missing, install only the editor; do not clone again. If the remote or branch is wrong, stop and run gh passport doctor. Do not delete the folder, reset Git, replace SSH keys, or paste a token into the remote URL. Use Request help without posting secrets on the Passport progress page if the doctor's named recovery command does not resolve the problem. Submit one issue without private information and return later; the reviewer does not need to be online.

        Understand Before Accepting AI Output#

        Do not let an AI assistant insert tokens, rewrite credential helpers, change the remote, or switch branches without explaining the exact reason. Verify the identity, remote, and branch yourself before accepting its claim of success.
