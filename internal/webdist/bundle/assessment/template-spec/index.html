    The repository contains fictional fixtures, empty evidence templates, a non-secret route catalogue, and no privileged workflow. gh passport start creates a learner's public personal fork, route-specific passport.json, onboarding/<username> branch, and permanent draft PR into the central public repository.

    Private Authority#

    The private control repository stores:

    • active enrollment with learner and reviewer GitHub usernames;
    • immutable numeric user, reviewer, fork, parent, base-repository, and PR IDs;
    • canonical platform, responsibilities, missions, baseline, and exact protected hash of passport.json;
    • minimal Check Run projection, review state, lifecycle event, and completion record.

    It never stores learner answers, prompts, broad logs, credentials, research data, or analytics.

    Student Tasks#

    Every learner completes core safety scenarios. Additional tasks apply only when the selected responsibility requires them:

    1. Complete a manual Git branch/diff/commit/PR baseline for Git work.
    2. Fix a small Python defect and add or repair a test for Python work.
    3. Complete a manual task before a comparable bounded agent-assisted task and record personal verification, one accepted decision, and one rejection or revision without including a transcript or secret.
    4. Submit and inspect a tiny CPU job, interpret accounting, cap an array, and map storage for Euler CPU work.
    5. Correct a static unsafe GPU request and explain one-GPU scaling evidence for Euler GPU work; no live GPU allocation is required.
    6. Complete placement, collaboration, and handover evidence for data work.
    7. Complete Blade or supervisor scenarios only when those responsibilities apply.

    Deterministic Checks#

    Check Blocking condition
    Hidden behavior test Route-specific fixture behavior is incorrect or does not run in isolation
    Secret patterns Credential-like value exists; execution and optional AI review stop first
    Repository boundaries Large file, checkpoint, dataset, environment, cache, symlink, or unselected path is committed
    Commit convention Commits after the immutable baseline lack valid type(scope): summary form
    PR contract Purpose, verification, risks, and AI assistance are missing
    Agent evidence Manual baseline, bounded task, personal verification, decision, or limitation is missing
    Slurm policy CPU, memory, time, GPU, logging, or concurrency request is unsafe or unbounded
    Protected files Curriculum, route, passport.json, workflow, rubric, or policy fixture changed
    Evidence schema Required route evidence or curriculum version is absent

    The rubric is not secret trivia. Editable paths are explicit. Hidden controller checks and trusted hashes remain private.

    Trust And Isolation#

    Registration accepts only one open draft PR whose immutable author ID, public fork ID, direct parent ID, branch, base, canonical route, and passport.json match an active private enrollment. Assessment revalidates the exact head SHA before and after isolated execution.

    Student-controlled workflows receive no privileged token or organization secret. Do not use pull_request_target to execute learner content. The controller checks out the public fork without persisted credentials and runs untrusted behavior in an ephemeral read-only, network-disabled, bounded container.

    The GitHub App is installed only on passport-exercises. It has read-only Contents and write access to Checks, Issues, and Pull requests. The private control repository's own GITHUB_TOKEN persists bounded authority paths. Neither credential can write to a learner fork.

    Retry And Recovery#

    Students revise the same branch and PR. Checks rerun on each pushed commit. A closed unmerged PR can be replaced by rerunning gh passport start; the controller rotates its trusted PR number only after complete revalidation. A merged PR, changed route, ambiguous PR, or stale approval stops safely.

    Definition Of Ready#

    • Curriculum, public export, extension, controller, registry, and three-OS CI pass for one frozen release.
    • Public main is protected; force pushes and deletions are disabled.
    • The controller App and private control secrets have reviewed least privilege.
    • One synthetic non-admin learner proves start, public PR, exact-SHA check, correction, asynchronous human approval, immutable record, and lifecycle.
    • Windows, macOS, and Linux release assets install and run on clean machines.
    • Human reviewers and a private incident path are assigned.
