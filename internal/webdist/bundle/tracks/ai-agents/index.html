    AI Agent User

    Select this if you will use a coding agent: an AI tool that can read or edit files and run commands after your approval in a lab project folder. Ordinary chatbot use outside lab work is not included.

    Sequence

    Practice in this order.

    Routine lessons use automatic checks. A person is involved only for a named exception or real operational decision. Active-time estimates exclude installation, access approval, cluster queues, and support wait.

      Set Up One AI Coding Tool Safely

      An AI coding tool can inspect project files and propose edits or commands. Set up one such tool for the fictional practice project. Learn which account provides access, what may cost money, where any secret access key is stored, and how to confirm that setup changed no project file.
