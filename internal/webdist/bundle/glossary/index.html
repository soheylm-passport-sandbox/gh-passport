    glossary

    Glossary

    View this page on GitHubReturn to my progress
    Term Meaning
    2FA Two-factor authentication: a second proof requested after a password
    Account A personal identity used to access a service; never shared
    AI agent Software that can inspect, propose, or execute multi-step work; the human remains responsible
    Agent harness Runtime that coordinates model requests, context, tools, permissions, and edits
    ACP Agent Client Protocol connecting an external agent runtime to an editor interface
    API key Application programming interface key: secret text used by a program to access a service, sometimes with paid usage; protect it like a password
    Allocation CPUs, memory, GPUs, and time reserved for a Slurm job
    Artifact Generated output such as a checkpoint, log, figure, binary, or report
    Batch job Unattended work submitted to a scheduler, normally with sbatch
    Bash Shell used for commands on most Linux systems and on Euler; Terminal or an SSH connection starts it automatically
    Blade IDEAL Lab's shared remote Windows computer for licensed graphical engineering software and short interactive work
    Browser Application used to open websites, such as Firefox, Chrome, Edge, or Safari
    Branch A named line of Git work that keeps a set of changes separate until review or merge
    CAD Computer-aided design software used to create and inspect engineering geometry
    Clone A local copy of a Git repository, including its version history and remote connection
    Commit A recorded Git snapshot with an author and message
    Command Text instruction entered into a shell and started by pressing Enter
    Command line Text-based way to control a program by entering commands in a terminal
    Checkpoint Saved application/model state used to resume or preserve a run
    Checksum Calculated fingerprint used to detect whether a file changed
    Compute node Euler machine on which an allocated Slurm job executes
    Concurrency cap Maximum number of array tasks allowed to run simultaneously, written after %
    Conventional Commit Commit subject in type(scope): summary form
    Conda A tool that creates isolated software environments and installs packages into them
    Conda base environment Conda's shared default environment; project packages should use a separate project environment
    CPU General-purpose processor used by the operating system and most programs
    Data steward Person responsible for organization, access, lifecycle, and handover of shared data
    Diff Line-by-line representation of changes between file versions
    Directory Another word for a folder
    Download Copy a file from a website or remote service onto the current computer
    Durable storage Approved storage intended to keep required files under a defined ownership and recovery plan
    Euler tunnel SSH path into a running Slurm allocation, useful for interactive tools such as VS Code
    Editor Application used to read and change text or code files, such as VS Code or Zed
    Fair share Scheduling model that balances average use against a shareholder entitlement; not exclusive ownership
    File A named unit of stored information, such as a document, script, image, or dataset
    Folder A container used to organize files; also called a directory
    GPU Accelerator suited to specific parallel workloads; not automatically useful for every program
    Git Version-control software that records file changes and history on a computer
    GitHub A service that hosts Git repositories, pull requests, issues, and automation
    GitHub CLI The command-line program named gh used to interact with GitHub
    GitHub Education GitHub's eligibility program for current student benefits; approval and available benefits are controlled by GitHub
    GUI Graphical user interface controlled mainly through windows, menus, and buttons
    Host fingerprint Short identifier used to verify that an SSH server is the expected computer before trusting it
    Information owner Person accountable for classification and authorized use of information
    Install Add a program to a computer so it can be run there
    Interface Editor panel, terminal, app, or cloud surface through which a person interacts with an agent
    Job A program submitted to a scheduler to run with requested resources
    Job ID Number assigned by Slurm to identify one submitted job
    Link Clickable text or control that opens another page or location
    Login node Euler entry point for editing, transfer, and job management; not heavy computation
    Local On the computer in front of you, rather than another computer reached over a network
    Local server Program running on the current computer that provides a page or service only while it remains running
    Miniforge A small Conda distribution configured around the community-maintained conda-forge package channel
    MFA Multi-factor authentication requiring more than a password
    MCP Model Context Protocol connecting an agent to external tools or context sources
    Mount Connect a remote storage location so it appears as a drive or folder on the current computer
    Model System that generates a response from supplied context; it does not by itself define agent permissions or billing
    Model gateway Service providing unified API access, routing, billing, or limits across model providers
    Model provider Service operating an endpoint that serves a model
    Module On Euler, a command-managed selection of a maintained software version for the current shell
    NAS Network-attached durable shared storage
    Network Connection that lets computers exchange data and reach remote services
    Operating system Basic software that runs a computer, such as Windows, macOS, or Linux
    Output Text or files produced after a command or program runs
    Package Reusable software installed into an operating system or project environment
    Passport endorsement Demonstrated capability such as code contribution or Euler GPU use
    Passphrase Local secret that unlocks an SSH private key; it is separate from the ETH account password
    Path Text address of a file or folder, such as C:\Users\Ada or /home/ada
    PowerShell Windows shell used to read and run the commands labelled PowerShell
    Private key Secret half of an SSH key pair; stays on the local computer
    Prompt Text and cursor shown when a shell is ready for the next command
    Public key Shareable half of an SSH key pair, commonly ending in .pub
    Pull request Reviewable proposal to merge a branch into another branch
    Python environment An isolated Python interpreter and package set used by one project
    Python interpreter Program that reads and runs Python code
    Program Instructions a computer can run; an application is a program intended for direct use
    Repository A project directory whose files and history are managed by Git
    Remote On another computer or service reached over a network
    Reproducibility Ability to recreate an environment, command, and result from recorded evidence
    RDP Remote Desktop Protocol, used to display and control a remote Windows desktop
    Server Another computer that provides a service over a network
    Share A folder or storage area made available over a network to authorized users
    SMB The network file-sharing protocol used by smb:// addresses in the NAS instructions
    Slurm Euler's workload manager and scheduler
    Scheduler Service that places submitted jobs on shared compute resources when suitable capacity is available
    Shell Program inside a terminal that reads commands; examples are PowerShell, zsh, and Bash
    SSH Secure Shell protocol for remote login and commands
    Source code Human-readable instructions and text files used to build or run software
    Test A repeatable check that compares actual program behavior with an expected result
    Terminal Application that provides a text window in which a shell accepts commands
    Temporary storage Working storage that may be cleaned or purged and must not hold the only copy of required data
    VPN Virtual Private Network; the official secure connection used to reach ETH-only services from outside the campus network
    WSL Windows Subsystem for Linux, an optional Linux environment inside Windows; do not install it on Blade without approval
    Working tree Local checked-out files, including uncommitted edits
    zsh Shell used by default in macOS Terminal
