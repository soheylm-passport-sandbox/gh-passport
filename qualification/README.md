# Public WebKit qualification

Generated by `scripts/export_gh_passport.py` in the handbook repository. Do not
copy private source, records or credentials here, or edit the frozen inputs.
Rerun the exporter from the reviewed clean source when they change.

The exporter includes the complete unchanged tracked TypeScript browser suite,
locked browser tools, two mission fixtures from the public exercise catalogue,
the already-exported agent contract, and route metadata from the public bundle.
Frozen inputs use `-text` Git attributes so a Windows autocrlf checkout preserves
their hashed bytes. No local checkout link or second website copy is needed. The static server reads
the actual `internal/webdist/bundle` that the launcher embeds.

`payload.json` records the exact source revision, curriculum and SHA-256 of all
assets, cases, fixtures and harness files. `node qualification/verify.mjs` refuses
changed, missing, extra or linked inputs, mismatched source/route/agent metadata,
and dirty-preview exports. Hashes detect accidental drift; they are not a signed
attestation against a maintainer who also rewrites the manifest. Review the
export against its clean source before pushing.

The release workflow calls one local reusable workflow on each PR/main/tag
execution. A Linux preflight verifies the public repository and payload before
allocating the standard Mac runner. All WebKit cases then run with one worker;
the tag's five binary builds require both native Go tests and WebKit success.
No secret inheritance, private checkout, private API or production assessment
permission is needed. Failure diagnostics and intermediate release artifacts
have one-day retention. Other final native/controller/browser gates still apply.

The single-worker configuration and native-animation preference preserve the
original test assertions. Only owned temporary WebKit app-data is modified and
removed after the run; personal preferences, CSS animations and browser sandbox
protections remain unchanged.

To check an export locally after installing its locked tools:

```text
node qualification/verify.mjs
pnpm --dir qualification/web exec playwright test --project=webkit --workers=1
```

Use `PASSPORT_PUBLIC_TEST_PORT` for an unused loopback port. Keep generated
node_modules, reports and test-results out of Git. Native test names, including
`test (macos-latest)`, remain stable while using an explicit standard Intel Mac.
